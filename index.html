🎮 Cara Bermain di HP Android, Tablet, Laptop, & Komputer

ARENA JUARA 2026 — KARYA SDN KESILIR 02 WULUHAN dirancang agar setiap siswa aktif melakukan aksi nyata (melompat, berlari, menarik tambang, menyerang/bertahan, memutar roda, menyusun kata, mencocokkan pasangan, dan menangkap target) sambil menjawab pertanyaan sesuai kelasnya.

  • Kontrol Layar Sentuh (HP Android / Tablet): Tekan tombol aksi besar berwarna di sebelah kanan/bawah layar permainan.
  • Kontrol Keyboard Pemain 1: Tombol W / Spasi untuk Lompat/Lari/Tarik, serta tombol angka 1, 2, 3, 4 untuk memilih jawaban cepat.
  • Kontrol Keyboard Pemain 2 (Mode Duel 2 Pemain): Tombol Panah Atas (↑) / Enter untuk Aksi P2, serta tombol angka 7, 8, 9, 0 untuk memilih jawaban Pemain 2.
